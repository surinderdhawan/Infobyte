# InfoByte Tech Pvt - Company Website

A modern, visually appealing website for InfoByte Tech Pvt built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- 🎨 Modern dark theme with gradient accents
- ✨ Smooth animations using Framer Motion
- 📱 Fully responsive design
- 🚀 Fast and optimized with Next.js 14
- 🎯 SEO-friendly structure
- 💼 Showcases IT services and solutions

## Tech Stack

- **Next.js 14** - React framework
- **TypeScript** - Type safety
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **ESLint** - Code quality

## Getting Started

### Prerequisites

- Node.js 14+ (recommended: Node.js 18+)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm start
```

## Project Structure

```
├── app/
│   ├── globals.css      # Global styles and theme
│   ├── layout.tsx       # Root layout
│   └── page.tsx         # Home page

│   ├── About.tsx        # About section
│   ├── Contact.tsx      # Contact form
│   └── Footer.tsx       # Footer
└── public/              # Static assets
```

## Customization

### Theme Colors

Edit `tailwind.config.ts` to customize the color scheme:
- Primary colors: Blue gradient
- Secondary colors: Purple gradient

### Content

Update the content in each component file:
- Services: `components/Services.tsx`
- About section: `components/About.tsx`
- Contact information: `components/Contact.tsx`
